# X Article Summarizer

指定したタグ（キーワード）に関する X の人気投稿を周期的に収集し、期間別ランキング・記事まとめ・各投稿へのリンクをレポートとして表示します。

- **収集**: GitHub Actions が毎時 `collector/collect.py` を実行し、[FxTwitter (FxEmbed)](https://github.com/FxEmbed/FxEmbed) の公開 API から投稿を取得して `docs/data/*.json` にコミット
- **表示**: GitHub Pages が `docs/` を配信（`index.html` / `style.css` / `app.js`）

## 使い方

- **検索**: 画面上部の検索欄にキーワードを入れると、いまの X の人気投稿をその場で検索します（期間・最低いいね数・言語を指定可能）。
- **タグに追加**: 検索結果の「タグに追加して定期調査」または「＋ タグを追加」で、そのキーワードを定期調査の対象にします。
- **調査項目**: タグごとに「直近 1 時間 / 24 時間 / 1 週間」の各ランキングを調査するかと、それぞれの最低いいね数を設定できます。
- **アカウントのフォロー**: 検索欄に `@ユーザー名` かプロフィール URL を入れるとアカウントを表示し、「フォローして定期収集」でそのアカウントの投稿を定期的に集めます（`topics.json` では `"kind": "account"` の項目）。
- **編集・削除**: タグ名の右の「⋯」、またはタグ画面の「編集」「削除」から行えます。フォロー解除も同様です。
- **フィルター**: 「フィルター」で、指定したワードを含む投稿だけを抽出、または除外できます（投稿者名・@アカウント名にも一致）。設定はタグごとにブラウザへ保存されます。
- **翻訳**: 外国語の投稿には「翻訳」ボタンが付きます。Chrome / Edge 内蔵の Translator API を使い、端末内で翻訳します（無料・API キー不要。初回のみ言語ごとの翻訳モデルをブラウザがダウンロードします）。「自動翻訳」をオンにすると外国語の投稿をまとめて翻訳します。非対応のブラウザでは Google 翻訳を開くリンクになります。
- **GitHub 連携**: タグの追加・編集・削除は画面から `topics.json` に書き戻します。初回のみ「設定」に、このリポジトリの Contents を Read and write にした fine-grained トークンを登録してください（トークンはブラウザ内にのみ保存されます）。

## `topics.json`

画面から編集できますが、直接編集しても構いません。push すると収集がすぐに走ります。

| キー | 内容 |
| --- | --- |
| `id` | 半角英小文字・数字・ハイフンの識別子 |
| `name` | 表示名 |
| `query` | X の検索クエリ（`OR`、`"完全一致"`、`from:` などの演算子が使えます） |
| `lang` | 言語コード（`ja` / `en`、空なら指定なし） |
| `windows` | 調査項目の配列。`{"hours": 1 \| 24 \| 168, "min_faves": 最低いいね数}` |
| `accounts` | 投稿を集めるアカウント（任意） |
| `keywords` | アカウントの投稿をこの語のいずれかを含むものに絞る（空なら全件） |
| `include_replies` | 返信を含めるか |
| `interval_min` | 収集間隔（分、最短 15。Actions の起動は毎時なので実質 60 分単位） |
| `max_pages` | 期間ごとに取得する検索ページ数（1 ページ約 20 件、最大 5） |

`settings.retention_days` より古い投稿は削除され、本文は `settings.text_limit` 文字までの抜粋のみ保存します。

## ローカルで試す

```bash
python collector/collect.py --force
python -m http.server 8765 --directory docs
```

## 利用上の注意

- FxTwitter は非公式の公開 API です。リクエストは間隔を空けて最小限にしており、仕様変更や制限で取得できなくなる場合があります。
- 公開リポジトリの GitHub Pages では収集結果が誰でも閲覧できます。個人の情報収集の範囲で利用し、投稿の転載・再配布は避けてください（各投稿の著作権は投稿者に帰属します）。
